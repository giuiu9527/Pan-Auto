# Pan-Auto · 百度网盘自动转存

定时把好友分享的链接 / 聊天发来的文件夹自动转存到自己的网盘，带关键字重命名清洗。

## 运行

```bash
pip install -r requirements.txt
python main.py
```

## 在线更新

底部状态栏「检查更新」会启动程序目录里的独立更新器 `update.exe`：读取更新清单 → 比较版本 → 下载 → SHA-256 校验 → 关闭主程序覆盖安装 → 自动重启。发版步骤与协议见 [docs/UPDATE.md](docs/UPDATE.md)。

```powershell
.elease.ps1 -Version 3.0.1     # 写 VERSION -> 提交推送 -> 打包 -> 发布到 OpenList 并自检
```

跳过启动时的静默更新检查：`$env:PAN_AUTO_DISABLE_UPDATE = "1"`。

## 功能一览（V3.0）

- 概览页：任务数 / 累计同步文件 / 最近同步 / 24 小时错误
- 自动同步：分享链接、群「具体文件夹」、好友 / 整群 定时增量转存（去重、去广告、关键字改名）
- 好友 / 群文件：手动浏览多级文件夹并转存，或一键加入定时同步
- 批量重命名（替换 / 删除 / 正则 / 前后缀，实时预览）、广告清理（关键词 + 白名单）、广告插入
- 多账号（百度 / 夸克 Cookie），WebView2 浏览器登录，运行记录筛选搜索，托盘常驻，开机自启
- 同步可靠性：目录创建冲突不再生成 `xxx_日期_时间` 副本；所有好友 / 群任务经中转目录合并落盘，增量就地更新不产生 `(1)(2)`；任务串行 + 失败退避

## 已知限制

- 夸克分享转存按公开协议实现，未用真实夸克账号端到端验证；夸克扫码登录未做
- 「分享链接同步」暂不支持只同步分享内的某个子文件夹
